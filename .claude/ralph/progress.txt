  - reset_all_one_shots(): Reset all one-shot triggers
  - clear(): Clear all configs and reset state

  - ONE_SHOT: Triggers exactly at specified step, only fires once (tracked in _triggered_one_shots)
  - STEP_BASED: Triggers within [start_step, end_step] range (inclusive)
  - PROBABILISTIC: Uses seeded RNG for reproducible probabilistic triggering
  - PERIODIC: Triggers when current_step % every_n_steps == 0
