  - add_config(config): Add FaultConfig to scheduler (raises ValueError on duplicate)
  - remove_config(config_id): Remove config (raises KeyError if not found)

  - list_configs(): List all registered config IDs (sorted)
  - update_step(step): Update the current training step
  - get_step(): Get current step
  - should_trigger(config_id): Check if a specific fault should trigger
  - get_active_faults(): Get all faults that should trigger at current step
  - reset_one_shot(config_id): Reset a one-shot trigger to fire again
  - reset_all_one_shots(): Reset all one-shot triggers
  - clear(): Clear all configs and reset state
  - set_seed(seed): Set random seed for probabilistic triggers
- Trigger type support:
  - ONE_SHOT: Triggers exactly at specified step, only fires once (tracked in _triggered_one_shots)
  - STEP_BASED: Triggers within [start_step, end_step] range (inclusive)
  - PROBABILISTIC: Uses seeded RNG for reproducible probabilistic triggering
  - PERIODIC: Triggers when current_step % every_n_steps == 0
